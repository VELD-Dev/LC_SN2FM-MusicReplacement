# Titan-Class Meltdown
Sets **Facility Meltdown** music's to Subnautica 2 soundtrack "Titan-Class Biosignatures" ([timecode](https://youtu.be/BH5PwYNSuhQ?t=127)) by Ben Prunty  
  
*Please check out my real mods too :p*  
  
For quite obvious reasons, **this mod will not do anything without Facility Meltdown.**  
  
> [!IMPORTANT]
> **Also requires [loaforcsSoundAPI](https://thunderstore.io/c/lethal-company/p/loaforc/loaforcsSoundAPI/)**
